# LicenseKit

Binary distribution of **LicenseKit** — a Swift SDK for selling software: define
licenses in code, issue them as signed files, validate them offline or against a
store's API.

This repository carries the Swift package manifest. The XCFrameworks themselves
are attached to each [release](https://github.com/gumbracelet/LicenseKit-SDK/releases); they are
not stored in git, so resolving this package downloads only the version you ask
for.

## Install

```swift
dependencies: [
    .package(url: "https://github.com/gumbracelet/LicenseKit-SDK.git", from: "1.0.0")
],
targets: [
    .target(
        name: "YourApp",
        dependencies: [
            .product(name: "LicenseKit", package: "LicenseKit-SDK")
        ]
    )
]
```

In Xcode: **File → Add Package Dependencies…** and paste
`https://github.com/gumbracelet/LicenseKit-SDK.git`.

### Pinning a binary target directly

If you vendor binary targets by hand rather than depending on this package:

```swift
.binaryTarget(
    name: "LicenseKit",
    url: "https://github.com/gumbracelet/LicenseKit-SDK/releases/download/1.0.0/LicenseKit.xcframework.zip",
    checksum: "b507c8ad219afcf874609d6c258dc1b83bbd834d851e164bc78badd6ab25b27c"
)
```

Every module is published this way. Checksums for all of them are in
[`checksums.txt`](https://github.com/gumbracelet/LicenseKit-SDK/releases/download/1.0.0/checksums.txt) on each release, and in the
`.binaryTarget` entries in `Package.swift`.

## Products

| Product | Platforms | Use it for |
| --- | --- | --- |
| `LicenseKit` | iOS, macOS, tvOS, watchOS, visionOS | Validating licenses in your app. This is the one you want. |
| `LicenseKitVendor` | macOS only | Issuing and signing licenses from your own backend or tooling. Never link this into a shipping app. |

`LicenseKitVendor` has no iOS slice by design — the type that mints licenses
cannot be linked into an iOS app even by accident.

## Note on binary distribution

These frameworks are built with library evolution enabled, so a `switch` over a
non-frozen public enum needs an `@unknown default` case. The API is otherwise
identical to the source distribution.
