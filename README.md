# LicenseKit SDK

Binary distribution of [LicenseKit](https://github.com/gumbracelet/LicenseKit) —
prebuilt XCFrameworks, published as GitHub release assets.

This repository carries the Swift package manifest only. The binaries themselves
are attached to each [release](https://github.com/gumbracelet/LicenseKit-SDK/releases);
they are not stored in git.

Generated by `Scripts/licensekit-release`. Do not commit to this repository by hand.
